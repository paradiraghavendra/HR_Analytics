# 📊 HR Analytics Project

An end-to-end HR Analytics solution designed to analyze employee attrition, performance, and workforce demographics. This project demonstrates a complete data analysis pipeline—moving from raw data cleaning in **Excel**, querying and aggregating data in **MySQL / PostgreSQL**, to building interactive dashboards in **Power BI**.

---

## 📌 Project Overview

Understanding why employees leave and identifying key workforce trends is critical for HR decision-making. This project explores key metrics such as **Attrition Rate**, **Average Tenure**, **Job Satisfaction**, and **Work-Life Balance** to provide actionable insights for organizational retention strategies.

### Key Objectives
- Identify key drivers of employee turnover.
- Measure job satisfaction across different departments and roles.
- Analyze income disparities relative to experience and position.
- Deliver an interactive dashboard for HR leaders to monitor retention metrics in real time.
